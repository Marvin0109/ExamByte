Datenschutzerklärung

Stand: 13.09.26

1. Allgemeine Informationen

ExamByte ist ein privates Lern- und Demonstrationsprojekt, das zu Lern-, Übungs-, Test- und Demonstrationszwecken entwickelt wurde.

Die Plattform wird kostenlos zur Verfügung gestellt und nicht als kommerzieller Dienst betrieben.

Diese Datenschutzerklärung informiert darüber, welche personenbezogenen Daten bei der Nutzung von ExamByte verarbeitet werden und wie mit diesen Daten umgegangen wird.

2. Hosting

ExamByte wird auf einem virtuellen privaten Server (VPS) des Anbieters MVPS betrieben.

Beim Aufruf der Website können technische Verbindungsdaten verarbeitet werden, die für den Aufbau und die Aufrechterhaltung der Verbindung sowie für den sicheren Betrieb der Website erforderlich sind.

3. Anmeldung mit GitHub

ExamByte verwendet GitHub OAuth zur Authentifizierung von Nutzern.

Wenn Sie sich mit GitHub anmelden, werden Sie zur Authentifizierung zu GitHub weitergeleitet. GitHub stellt ExamByte anschließend die für die Identifizierung Ihres Kontos erforderlichen Informationen zur Verfügung.

ExamByte speichert dauerhaft ausschließlich den GitHub-Benutzernamen in der eigenen Datenbank.

Andere Profilinformationen von GitHub werden von ExamByte nicht dauerhaft gespeichert.

Die Authentifizierung selbst erfolgt über den OAuth-Dienst von GitHub. Für die Verarbeitung von Daten durch GitHub gelten die Datenschutzbestimmungen von GitHub.

4. Gespeicherte Nutzerdaten

In der Datenbank von ExamByte wird dauerhaft folgende Information gespeichert:

  • GitHub-Benutzername

Derzeit bietet ExamByte keine Funktion an, mit der Nutzer ihr Konto bzw. ihre gespeicherten Daten selbst über die Website löschen können.

Für Anfragen bezüglich der gespeicherten personenbezogenen Daten können Sie sich über die unten angegebene Kontaktadresse an den Betreiber wenden.

5. Sitzungsdaten und Cookies

ExamByte verwendet technische Sitzungsfunktionen, um eine angemeldete Sitzung aufrechtzuerhalten.

Hierzu kann beispielsweise ein Session-Cookie wie JSESSIONID im Browser gespeichert werden.

Dieses Cookie dient der Aufrechterhaltung der Sitzung und wird nicht für Werbung oder Nutzer-Tracking verwendet.

ExamByte verwendet keine Analyse-Dienste, Werbe-Cookies, Tracking-Pixel oder vergleichbare Tracking-Technologien.

6. Cloudflare

ExamByte verwendet Cloudflare für DNS-Verwaltung, Reverse-Proxying, Sicherheitsfunktionen und den Schutz vor schädlichem oder missbräuchlichem Datenverkehr.

Beim Aufruf von ExamByte können Anfragen daher zunächst über die Infrastruktur von Cloudflare verarbeitet werden, bevor sie den ExamByte-Server erreichen.

Dabei können technische Informationen wie IP-Adressen und Informationen über Anfragen verarbeitet werden, soweit dies für die Bereitstellung und Absicherung der verwendeten Cloudflare-Dienste erforderlich ist.

Für die Verarbeitung personenbezogener Daten durch Cloudflare gelten die Datenschutzbestimmungen von Cloudflare.

contact@exambyte.org
